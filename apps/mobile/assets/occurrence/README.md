# Bundled occurrence sample

These seven JSON files are deterministic 600-record samples of the frozen Atlas of Living Australia GeoJSON files stored in the team's shared Google Drive dataset folder.

The records were selected at evenly spaced source indexes, including the first and last record. This keeps the mobile bundle small while preserving authentic coordinates, dates, licence fields and record metadata. The app identifies this as a sample; the full frozen files remain the authoritative project dataset.
